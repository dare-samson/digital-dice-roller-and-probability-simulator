# Digital Dice Lab

**Digital Dice Lab** is a responsive dice roller and probability simulator built with HTML, CSS, and vanilla JavaScript. Roll virtual dice, run repeated trials, and compare the experimental results with the theoretical probability distribution.

## Features

- Roll between 1 and 6 dice, each with 2 to 20 sides.
- Simulate between 100 and 100,000 rolls.
- Compare the experimental mean and sum frequencies with calculated theoretical probabilities.
- View the most likely total and a chart of the results.
- Use the responsive interface on desktop or mobile; no build tools or packages are required.

## Run locally

Download or clone this repository, then open `index.html` in a modern web browser. The app runs entirely in the browser.

## Publish with GitHub Pages

1. Create a **public** GitHub repository and upload `index.html`, `styles.css`, `app.js`, and `README.md` to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
4. Once GitHub Pages finishes deploying, the app will be available at `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`.

The GitHub Pages address will be shown in the repository's Pages settings. Replace the example address with your GitHub username and repository name before sharing it.
